# NewCuts Barbershop

NewCuts Barbershop is a modern barbershop website built with Next.js. The project showcases premium grooming services, a polished brand experience, and a booking-focused landing page for clients looking to schedule cuts, fades, shaves, and other grooming services.

## Features

- Modern, responsive design
- Premium barbershop branding and service highlights
- Book now and services navigation
- Built with Next.js, React, and Tailwind CSS

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js 18 or later
- npm

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Then open http://localhost:3000 in your browser to view the app.

### Production build

```bash
npm run build
```

To start the production server:

```bash
npm run start
```
